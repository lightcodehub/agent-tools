# 测试报告

> 唯一输出路径：项目根目录的 `tests/test-report.md`。使用本模板作为报告骨架，将 [单元分节模板](unit-test-report.md) 展开为 A 节；有设计或实际集成用例，或集成盘点不完整时，将 [集成分节模板](integration-test-report.md) 展开为 B 节，放在 C 节之前。不得把分节模板复制成独立报告，最终报告移除模板说明与占位内容。
>
> 本报告的 A、B 节根据同一轮源码、配置、盘点与实际结果整体重建；C 节只记录历史与负向验证摘要。失败、中断或未启动也记录真实结果；不拼接历史通过结果。只写最小诊断摘要，不粘贴完整样本、原始日志或编码数据。无 YAML Front Matter。
