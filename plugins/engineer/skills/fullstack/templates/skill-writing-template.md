# 内部 skill 编写参考

产出可复用库/工具时，按此参考在 `.claude/skills/{skill-name}/SKILL.md` 编写。

---

## 格式

```yaml
---
description: { { 一句话描述这个库/工具能干什么 } }
when_to_use: |
  {{何时触发，含典型表达}}
argument-hint: <{{参数提示}}>
allowed-tools: { { 按需列出，如 Read Bash Edit } }
---
```

body 只写能力范围，不写角色/流程/禁止事项：

| 章节     | 必填 | 说明                             |
| -------- | ---- | -------------------------------- |
| 概述     | 是   | 名称、工具路径、用途、适用场景   |
| 核心能力 | 是   | 能力 + 入口（函数/命令）对照表   |
| 用法     | 是   | 最小可运行示例                   |
| 依赖脚本 | 否   | 有则列出，脚本位于 `scripts/` 下 |

---

## 内容

### 概述

- **名称**：{{名称}}
- **工具路径**：`{{项目内库/工具所在目录}}`
- **用途**：{{一句话}}
- **场景**：{{何时用}}

### 核心能力

| 能力       | 入口            |
| ---------- | --------------- |
| {{做什么}} | `{{函数/命令}}` |

### 用法

```{{语言}}
{{最小示例}}
```
