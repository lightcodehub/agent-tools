| 入口 | 用法 |
| --- | --- |
| [developer](skills/developer/README.md) | `/engineer:developer 按 design-doc/index.md 实现并交验` |
| [discover-skills](skills/discover-skills/SKILL.md) | `/engineer:discover-skills /path/to/project both`，最后一个参数可选 `codex`、`claude` 或 `both`。 |
