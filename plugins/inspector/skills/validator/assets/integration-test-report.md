> 本节统计单位为参数实例，框架方法数另列为执行信息；未实现和未运行实例也须进入明细及总数。不能用一个方法 PASS 替代全部实例结果，不能声称原始日志包含其未记录的参数信息。
>
> 盘点完整时，总数等于五类结果之和及各模块明细之和。通过率 = PASS 数 / 全部用例数；零用例写“—”。盘点不完整时，结果计数标明“已知”，集成用例总数和通过率写“未知”，说明缺失范围。
>
> 集成状态依据同轮最后一次尝试：存在最终集成失败用例或确认影响集成执行的错误 → FAIL；否则存在集成跳过、未实现、未运行、零用例、盘点不完整、执行未完成或混合结果无法可靠拆分 → INCOMPLETE；只有非空集成用例集全部实际通过且确认完整执行 → PASS。若混合命令仅因 UT 失败而非零退出，已确认完整通过的集成集仍为 PASS，UT 失败写入同一报告的 A 节。先前重试失败保留说明，模块集成状态按相同规则判定。

> 范围外未运行用例也如实登记，可能使项目集成部分为 INCOMPLETE；本次实施是否完成按授权范围的集成验收另行说明，不扩大实施范围。
